# Valley Sentinel website: ideas, problems and questions

This is the public help desk for the **Valley Sentinel website** (valleysentinelnews.com).

**Have an idea, a problem or a question about the website?**
- Press **New issue** above and pick *Suggest a feature*, *Report a problem* or *Ask a question*. You need a free GitHub account.

**Please remember:** this page is public. Anything you write here can be read by anyone, and your GitHub username is shown. Don't post private information such as an email address, phone number or home address.

We read everything. We can't build every idea, but we'll tell you what we decide. Labels you may see: **accepted** (we plan to build it), **shipped** (it's on the site), **declined** (not for now).

**Not about the website?** The app: https://github.com/valleysentinel/app-feedback. News tips, corrections, advertising and subscriptions: https://valleysentinelnews.com/contact/
